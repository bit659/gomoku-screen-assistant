# 五子棋交点小图标注工具（项目第一部分）

用于把真实五子棋小程序截图中的棋盘，分割成 **225 个交点小图**，并支持人工
分类（空交点 / 黑棋 / 白棋）后**保存成参照图包**，供项目第二部分的自动识别
软件加载比对。

**多图支持**：可同时导入多张截图、对每张图分别拉框与标注，最后把**所有图片**
选中的样本合并导出一个完整的参照图包。例如"带最新落子标志"的黑/白棋与普通
棋子不会出现在同一张截图上，就需要多张图各取所需。

- 技术栈：Python 3 + tkinter（界面）+ Pillow（图像处理）
- 运行环境：Windows（本工具已在 Windows 上验证）
- 项目位置：`D:\opencv-gomoku\board-crop-labeller\`

## 操作步骤

### 1. 导入图片（可多张）

点顶部「导入图片（可多选追加）」，可一次选择多张截图，也可多次追加。
顶部下拉框切换当前图片；每张图的拉框、分割、分类状态**相互独立**。

### 2. 拉框（页①，点击式，无需按住左键）

画面中有贯穿整个画布的**橙色十字参考线**，即当前逻辑光标位置：

- **左键点击 / 回车** = 选框角：
  - 第一击：定第一个框角（此时清除上一次的参考线）；
  - 移动鼠标（不用按键）：正方形框实时跟随显示；
  - 第二击（左键或回车）：完成拉框；
- **方向键** = 按**图像坐标**微调逻辑光标（默认 0.5px，按住 Shift 时 5px），
  适合放大后精确定位棋盘边线；回车与左键功能完全一致，
  防止手动按键导致鼠标错位；
- **右键拖动** = 平移画面（平移/缩放后十字线仍钉在原图像点）；
- **滚轮** = 以光标为中心缩放。缩放/平移已做**流畅化**：交互期间按
  30ms 节流合并重绘、用 BILINEAR 快速重采样（比 LANCZOS 快约 2 倍），
  停止滚动 230ms 后再用 LANCZOS 精化一次，保证画质与流畅兼顾。
- 状态栏会实时显示光标图像坐标。

> 提示：键盘方向键/回车需要先点击画布（或导入后画布已自动获得焦点）。

### 3. 自动分割

第二击完成即自动分割，并跳到页②。页①原图上会叠加三层线：
- 橙色细线 = 15×15 棋盘网格；
- 青色粗线 = 225 个小图的**裁剪边界**（相对网格整体外扩半格）；
- 深绿色粗框 = 你拉的框。

（重新拉框时旧的三层参考线会先被清除，再显示新框的。）

页①顶部按钮（从左到右）：
1. **清除当前分割线并重新拉框** = 清掉当前图的网格/裁剪线/拉框与 225 个小图，
   回到页①等待重新拉框（不会删除已导入的图片）；
2. **导出分割线预览图** = 把当前图的三层线叠加结果另存为 PNG。

### 4. 人工分类（页②，每张图独立）

- 上方三个按钮切换当前类目：**空交点 / 黑棋 / 白棋**；
- 在 225 个小图网格上**点击**小图 = 加入当前类目，再点一次 = 移出；
  每个交点最多归属一个类目（换类目点击会自动从旧类目移除）；
  每个格子尺寸与间距固定（选中只变边框颜色），布局不会缩放；
  小图铺满格子、外框紧贴图片（无内边距白边），边框四边等宽对称；
- 顶部可「清空当前类目」/「清空当前图全部」（只影响当前图片）；
- 页②按钮顺序：空交点 / 黑棋 / 白棋 → **重新生成 225 小图** → 清空当前类目 → 清空当前图全部 →
  保存参照图包。其中「重新生成 225 小图」按当前拉框重新分割并重建网格
  （会重置本图的分类选择）。

### 5. 保存参照图包（合并所有图）

点「保存参照图包（合并所有图）」，选择保存目录后，软件把**每张已拉框图片**
中被选中的小图全部合并导出到 `empty/ black/ white` 三个子目录 + `meta.json`。

## 分割算法（关键：半格平移）

棋盘是 15×15 = 225 个交点、14 个网格间隔。若直接在拉框内等分 14 段，
截到的是"格点方块"；**每个交点小图必须以交点为中心、向四周各外扩
半个网格边长**。因此裁剪边界 = 15×15 网格线整体平移半格，外圈再向外
延伸半格：

```
拉框:   box = (x0, y0, x1, y1)，边长 side = x1-x0
网格:   cell = side / 14（一个网格边长）
边界:   bounds[k] = x0 + (k - 0.5) * cell，k = 0..15
第 r 行第 c 列小图 = 图像裁剪 (bounds_x[c], bounds_y[r],
                                bounds_x[c+1], bounds_y[r+1])
```

- 中心对齐：每个小图中心恰好落在交点 (x0 + c·cell, y0 + r·cell)；
- 外扩效果：最外圈裁剪边界比拉框每边再长出半个网格（青线在深绿框外侧）。

> 提示：拉框时请让棋盘四周离图片边缘留出**至少半个网格**的余量，
> 否则最外圈交点小图会被图片边界裁掉（软件会给出越界数量提示）。

## 参照图包输出格式

```
参照图包目录/
├── empty/                 # 空交点（子目录名 = 类目内部键）
│   ├── 00_00_00.png       # 文件名 = 图序号_行_列（0 起，两位补零）
│   └── ...
├── black/                 # 黑棋
├── white/                 # 白棋
└── meta.json
```

**文件名带图序号前缀**（如 `01_07_07.png` = 第 2 张图第 7 行第 7 列），
不同截图里的同名交点不会互相覆盖。

`meta.json` 关键字段（供第二部分使用）：

```json
{
  "version": 2,
  "grid_n": 15,
  "source_count": 2,
  "sources": [
    {
      "name": "截图1.png",
      "image_size": [1000, 1000],
      "box": [150, 150, 850, 850],
      "cell": 50.0,
      "half": 25.0,
      "clamped_out_of_bounds": 0,
      "selected": {"empty": ["00_00_00.png", "..."], "black": [], "white": []}
    },
    { "name": "截图2.png", "...": "..." }
  ],
  "categories": {
    "empty": {"display": "空交点", "files": ["00_00_00.png", "01_05_05.png", "..."]},
    "black": {"display": "黑棋", "files": ["..."]},
    "white": {"display": "白棋", "files": ["..."]}
  }
}
```

### 第二部分识别软件怎么用它（思路）

1. 加载 `meta.json`，对 `sources` 里每张源图读取 `box / cell / grid_n`，
   用同样的 `crop_math.crop_intersections` 把**任意新截图**按同一网格切出
   225 个小图（或直接按当前图的 box 定位）；
2. 对每个小图，分别与 `empty / black / white` 三个类目下的参照图
   计算相似度（如模板匹配 TM_CCOEFF_NORMED、直方图余弦、SSIM 等），
   取最高相似度类目作为该交点状态；
3. 多张参照图取"与当前类目所有参照的最大相似度"与"其他类目的最大
   相似度"做比较，可加置信度阈值过滤，避免误判。

## 常见问题

- **双击 start.bat 闪退**：命令行手动运行 `.venv\Scripts\python.exe main.py`
  查看报错信息。
- **提示找不到 tcl / Can't find init.tcl**：用了 PATH 上的 Doubao 运行时
  Python，请改用本目录 `.venv` 中的 Python。
- **生成的边缘小图被截**：拉框离图片边缘太近，把框往里缩，留出半格以上余量。
- **方向键/回车没反应**：先点击一下画布让画布获得键盘焦点。
- **某张图还没拉框就切走**：该图状态保留，切回来继续拉框即可；未拉框的图
  不会参与参照图包导出。
